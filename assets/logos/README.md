# Logos de BOSQYN AI

Guarda aquí los recursos gráficos oficiales de BOSQYN AI.

## Nombres de archivo recomendados

- `bosqyn-logo.png` — logo principal con fondo transparente (para el encabezado del sitio).
- `bosqyn-logo-white.png` — versión clara para fondos oscuros.
- `bosqyn-icon.png` — isotipo o símbolo cuadrado para favicon y pantallas pequeñas.
- `bosqyn-logo.svg` — versión vectorial, si está disponible.

## Cómo subirlos

En GitHub, abre `assets/logos`, pulsa **Add file → Upload files**, arrastra los archivos PNG, SVG o WEBP y confirma con **Commit changes**.

Esta carpeta almacena los logos. Para que aparezcan en el frontend hay que referenciarlos en HTML/CSS; subirlos aquí no sustituye automáticamente el logo actual.

Usa únicamente imágenes de las que tengas autorización de uso. No incluyas información privada en los metadatos de los archivos.
